Multi-Station Instrument Control System

A production PyQt5 application that runs twelve electrolysis test stations and is used daily by six full-time employees.

Oxylus Energy

Overview

At Oxylus Energy I designed and built an instrument-control application from the ground up. It now runs across twelve experimental stations and is used every day by six full-time employees to configure hardware, run experiments, monitor live telemetry, and coordinate electrolysis equipment.

How it works

  • Modular architecture: per-station configuration with real-time telemetry and synchronized schedule execution across stations.
  • Station-configuration framework: dynamic USB device mapping, so instruments can be attached and assigned without code changes.
  • Live sensor polling and safe schedule validation, catching bad experiment schedules before they reach hardware.

My role

I built the application's GUI and control software from the ground up, covering design, implementation, debugging, and hardware integration. I worked closely with one of Oxylus's engineers throughout to make sure the system met the team's needs, getting their feedback and help along the way, and I was able to reference the company's existing GUI as a starting point.
